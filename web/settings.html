Weekly email

Every Monday a summary (visitors, new messages, your to-do list) is collected by GitHub and emailed to you at about 7:40am. It uses a private key shared between the site and GitHub – generate it here and paste it into GitHub yourself, so it never passes through anyone else. Only make a new one if the old key is lost or leaked.
